# Бег сквозь сезоны

Браузерный 3D-раннер: беги по дороге, уворачивайся от снеговиков и грязевиков, собирай монетки и проходи уровни. Вокруг сменяются времена года, время суток и края: деревни, луга, горы, море, реки и снежные долины.

- `index.html` — 3D-версия (Three.js) с уровнями, бронёй и сюрпризами
- `2d.html` — первая 2D-версия

Управление: ← → или A/D — дорожка, ↑ или пробел — прыжок (дважды — двойной прыжок), P — пауза. На телефоне — свайпы.
